벡터 실험실

STEP 1 / 8 · 벡터란?

크기와 방향을 함께 가진 화살표

어떤 사람이 출발점에서 동쪽으로 4km, 북쪽으로 3km 걸었다.

이 이동은 화살표 하나로 나타낼 수 있다. 화살표의 길이는 ‘얼마나’(크기), 화살표가 가리키는 쪽은 ‘어디로’(방향)를 뜻한다. 이것이 벡터다. (4, 3)처럼 숫자 두 개로 쓴다.

크기 = 피타고라스 정리

x 성분과 y 성분이 직각삼각형의 두 변이 된다. 벡터의 크기(길이)는 빗변이다. (4, 3)의 크기는 √(4² + 3²) = 5다.

벡터는 ‘위치’가 아니라 ‘이동’

길이와 방향만 같으면 어디에 그려도 같은 벡터다(39쪽). 체크박스를 켜서 확인해 보자.

STEP 2 / 8 · 벡터 더하기와 빼기

(4, 3)만큼 걷고, 또 (2, 6)만큼 걸으면?

37쪽의 사람은 (4, 3)에 도착한 뒤 동쪽으로 2km, 북쪽으로 6km를 더 걸어 (6, 9)에 도착한다. 두 이동을 이어 붙이면 출발점에서 도착점까지 가는 화살표 하나가 생긴다. 이것이 합성 벡터다.

예상해 보자: 실제로 걸은 거리와 출발점~도착점 직선거리 중 어느 쪽이 길까?

보기

뉴턴의 평행사변형 (38쪽)

한 물체에 두 힘이 동시에 작용하면, 두 힘을 두 변으로 하는 평행사변형의 대각선 방향으로 움직인다. 가속도 (2, 6)과 (4, 3)이 동시에 생기면 실제 가속도는 대각선 (6, 9)이다. 크기는 약 10.82m/s²다. 걷기든 힘이든 계산은 똑같이 성분끼리 더하기다.

STEP 3 / 8 · 스칼라 곱과 단위벡터

숫자를 곱하면 길이가 늘고, i와 j로 쪼갤 수 있다

벡터에 숫자(스칼라) k를 곱하면 각 성분에 k가 곱해진다. 방향은 그대로이고 길이만 |k|배가 된다. k가 음수이면 방향이 반대로 뒤집힌다.

단위벡터 i와 j (40쪽)

i = (1, 0)은 x축 방향, j = (0, 1)은 y축 방향의 길이 1짜리 벡터다. 그래서 (4, 3) = 4i + 3j로 쓸 수 있다. “x축으로 4칸, y축으로 3칸”이라는 뜻이다.

해밀턴의 i, j, k와 같은 글자!

사원수 실험실에서 본 i, j, k가 바로 여기서 쓰인다. 해밀턴이 사원수의 ‘벡터 부분’을 i, j, k로 쓴 데서 지금의 표기가 나왔다.

STEP 4 / 8 · 점곱(내적)

한 벡터에 다른 벡터의 그림자를 드리우면

두 벡터 a, b의 점곱 a·b는 “a의 크기 × (a 방향으로 비친 b의 그림자 길이)”다. 그림자를 사영(projection)이라고 한다. 식으로는 a·b = ‖a‖ × ‖b‖ × cos θ다(41쪽). 결과는 벡터가 아니라 숫자 하나다.

책 예시
왜 a·b = a1b1 + a2b2일까? (44쪽)

a·b = (a1i + a2j)·(b1i + b2j)
    = a1b1(i·i) + a1b2(i·j) + a2b1(j·i) + a2b2(j·j)

i와 j는 서로 수직이라 cos 90° = 0이다. 그래서 i·j = j·i = 0이다. 또 i·i = 1 × 1 × cos 0° = 1이고 j·j = 1이다. 가운데 두 항이 사라지고 남는 것은

a·b = a1b1 + a2b2

각도를 몰라도 성분끼리 곱해서 더하기만 하면 된다. 위 계산판에서 두 방법의 답이 항상 같은지 확인해 보자.

STEP 5 / 8 · 기계와 벡터

퍼셉트론의 가중합은 사실 점곱이었다

퍼셉트론의 가중치를 벡터 w = (w1, w2)로, 데이터 점을 벡터 x = (x1, x2)로 보자. 가중합 w1x1 + w2x2는 바로 점곱 w·x다. 그래서 퍼셉트론의 판정은 이렇게 쓸 수 있다(44쪽).

w·x + b > 0 이면 +1,  아니면 −1

구분선은 언제나 w와 수직

구분선 위의 점은 모두 w·x = −b를 만족한다. 즉 w 방향으로 비친 그림자 길이가 모두 같다. 그런 점들을 이으면 w에 수직인 직선이 된다. w를 돌리면 선도 같이 돈다.

판정 = 그림자 길이 비교

w·x를 ‖w‖로 나누면 x를 w 방향으로 비춘 그림자 길이다. 이 길이가 기준 −b/‖w‖보다 길면 +1, 짧으면 −1이다. 편향 b는 이 기준점을 w 방향으로 밀고 당긴다.

STEP 6 / 8 · 초평면과 편향

점곱의 부호가 ‘어느 쪽’인지 알려 준다

48쪽의 네 데이터 점 a(3, 1), b(2, −1), c(−2, 1), d(−1, −3)을 가중치 벡터 w와 점곱해 보자. 점곱이 양수이면 구분선의 한쪽, 음수이면 반대쪽에 있다. 점곱의 크기는 구분선에서 얼마나 떨어져 있는지 알려 준다. 2차원에서는 선이지만, 차원이 높아지면 이런 경계를 초평면이라고 부른다.

정답 라벨
점xw·xw·x + b선까지 거리판정라벨일치?

편향 = 방향은 그대로, 선만 평행 이동 (48쪽)

b = 0이면 구분선은 반드시 원점을 지난다. 라벨이 ‘a, b, c / d’이면 c가 틀린 쪽에 남는다. 이때 편향 b를 더하면 w의 방향(선의 기울기)은 그대로 두고 선만 옮길 수 있다.

정답 선은 무한히 많다 (49쪽)

c와 d 사이로 지나가는 직선은 셀 수 없이 많다. 퍼셉트론은 그중 하나를 찾는다는 것만 보장한다. 처음 보는 데이터까지 잘 맞히는 ‘최상의’ 선을 찾는다는 보장은 없다. w를 끌어서 다른 정답도 찾아보자.

STEP 7 / 8 · 벡터를 행렬로 쓰기

컴퓨터는 화살표 대신 수의 배열을 본다

퍼셉트론을 프로그램으로 만들 때 필요한 것은 그림이 아니라 수를 다루는 일이다(49~50쪽). 데이터 점 (x1, x2)도, 가중치 (w1, w2)도 결국 수의 배열이다.

행렬

수를 행(가로줄)과 열(세로줄)로 배열한 것이다. 행이 m개, 열이 n개이면 m × n 행렬이라고 한다.

1  2  34  5  62 × 3 행렬

벡터 = 행이나 열이 하나인 행렬

열이 하나면 열행렬(n × 1), 행이 하나면 행행렬(1 × n)이다. 열행렬을 옆으로 눕히는 것을 전치(transpose)라고 하고, Aᵀ로 쓴다.

A = 43 → Aᵀ = 43

행렬로 점곱하기: AᵀB

두 열행렬은 그대로는 곱할 수 없다. 행렬의 곱은 앞 행렬의 열 개수 = 뒤 행렬의 행 개수일 때만 된다. 그래서 하나를 전치해서 (1 × n) × (n × 1) 꼴로 만든다. 결과는 1 × 1, 즉 숫자 하나다.

차원
A (열행렬)
B (열행렬)

이게 왜 중요할까?

코사인이나 각도를 구할 필요 없이 곱하고 더하기만 하면 점곱이 나온다(51쪽). 데이터 점이 수천 개여도, 각 점과 w를 이렇게 곱하기만 하면 구분선(초평면)에서 어느 쪽에 얼마나 떨어져 있는지 알 수 있다. 컴퓨터가 가장 잘하는 일이다.

STEP 8 / 8 · 종합

퍼셉트론을 한 줄로: y = f(wᵀx)

입력 [x1, x2, …, xn]을 열벡터 x, 가중치 [w1, w2, …, wn]을 열벡터 w로 쓰면 가중합 w1x1 + … + wnxn은 wᵀx다(52쪽).

y = −1 (wᵀx + b ≤ 0),    y = 1 (wᵀx + b > 0)

편향도 가중치로 만드는 기술 (53쪽)

편향 b만 따로 노는 것이 어색해 보인다. 그래서 언제나 1인 가짜 입력 x0 = 1을 하나 더 넣고, b를 그 입력의 가중치 w0로 본다. 그러면 w0·x0 = b·1 = b라서 계산 결과는 똑같고, 식은 더 단순해진다.

x = [x0, x1, x2] = [1, x1, x2],  w = [w0, w1, w2] = [b, w1, w2]

y = −1 (wᵀx ≤ 0),   y = 1 (wᵀx > 0)

STEP 6의 값으로 직접 계산해 보기

데이터 점

퍼셉트론 실험실과 이어 보기

학습 규칙 b ← b + y는 w0 ← w0 + y·x0 (x0 = 1)과 같다. 편향을 가중치로 바꾸면 모든 가중치를 같은 규칙 하나로 고칠 수 있다. 그래서 실제 프로그램은 대부분 이 방식을 쓴다.

한눈에 정리
  1. 벡터는 크기와 방향을 가진 양이다. (4, 3)처럼 성분으로 쓰고, 크기는 √(4² + 3²) = 5다.
  2. 벡터 덧셈·뺄셈은 성분끼리 한다. 이어 걷기와 평행사변형의 대각선이 같은 결과다.
  3. 스칼라 k를 곱하면 길이가 |k|배가 된다. (4, 3) = 4i + 3j처럼 단위벡터로 쪼갤 수 있다.
  4. 점곱 a·b = ‖a‖‖b‖cos θ = a1b1 + a2b2. 그림자(사영)의 길이를 재는 계산이고, 0이면 두 벡터는 수직이다.
  5. 퍼셉트론의 가중합은 점곱 w·x다. 구분선(초평면)은 w에 수직이고, 점곱의 부호가 어느 쪽인지 알려 준다.
  6. 편향 b는 선의 방향은 그대로 두고 평행 이동시킨다. 데이터를 나누는 선은 무한히 많고, 퍼셉트론은 그중 하나를 찾는다.
  7. 벡터는 행이나 열이 하나인 행렬이다. 점곱은 AᵀB, 즉 (1 × n) × (n × 1) 행렬 곱으로 계산한다.
  8. x0 = 1, w0 = b로 두면 퍼셉트론은 y = f(wᵀx) 한 줄로 정리된다.
Q1

(4, 3)과 (2, 6)을 이어 걸었을 때, 걸은 거리는 약 11.32km이고 직선거리는 약 10.82km다. 왜 직선거리가 항상 더 짧거나 같을까?

답 보기
두 벡터와 합성 벡터가 삼각형을 이룬다. 삼각형에서 두 변의 길이의 합은 나머지 한 변보다 길다. 그래서 ‖a‖ + ‖b‖ ≥ ‖a + b‖이다(삼각부등식). 두 벡터의 방향이 같을 때만 등호가 성립한다.
Q2

5 × (4, 3) = (20, 15)의 크기가 정확히 5 × 5 = 25가 되는 이유를 식으로 보여 보자.

답 보기
√(20² + 15²) = √(5²·4² + 5²·3²) = √(5²(4² + 3²)) = 5 × √(4² + 3²) = 5 × 5 = 25. 일반적으로 ‖k·v‖ = |k|·‖v‖다.
Q3

(3, 4)와 (−4, 3)의 점곱을 구하고, 두 벡터 사이의 각을 말해 보자.

답 보기
3 × (−4) + 4 × 3 = −12 + 12 = 0. 점곱이 0이므로 cos θ = 0, 즉 θ = 90°(수직)이다.
Q4

a = (1, 0), b = (1, 1) 사이의 각을 점곱으로 구해 보자.

답 보기
a·b = 1 × 1 + 0 × 1 = 1, ‖a‖ = 1, ‖b‖ = √2. cos θ = a·b / (‖a‖‖b‖) = 1/√2이므로 θ = 45°다. 점곱을 쓰면 각도를 몰라도 각도를 거꾸로 구할 수 있다.
Q5

퍼셉트론에서 w = (1, 2), b = −4일 때 구분선의 방정식을 쓰고, 그 선이 w와 수직인지 확인해 보자.

답 보기
w·x + b = 0 → x1 + 2x2 = 4. 이 선은 (4, 0)과 (0, 2)를 지나므로 선의 방향 벡터는 (−4, 2)다. (−4, 2)·(1, 2) = −4 + 4 = 0이므로 수직이다. STEP 5에서 w를 (1, 2), b를 −4로 맞춰 확인해 보자.
Q6

b = 0일 때 어떤 데이터 점이 구분선 바로 위에 있다면, 그 점(벡터)과 w의 관계는?

답 보기
구분선 위의 점은 w·x = 0을 만족한다. 점곱이 0이므로 그 점의 벡터는 w와 수직이다(52쪽). 그래서 원점을 지나는 구분선은 w에 수직인 직선이 된다.
Q7

STEP 6에서 w = (3, 1)일 때, 라벨 ‘a, b, c / d’를 모두 맞히는 b의 범위를 구해 보자.

답 보기
c가 +1이 되려면 w·c + b = −6 + 1 + b = −5 + b > 0, 즉 b > 5다. d가 −1이 되려면 w·d + b = −3 − 3 + b = −6 + b ≤ 0, 즉 b ≤ 6이다. a(10 + b), b(5 + b)는 이 범위에서 저절로 양수다. 그래서 5 < b ≤ 6이다. 선을 옮길 수 있는 폭이 아주 좁다. w의 방향을 바꾸면 더 넉넉한 선도 찾을 수 있다.
