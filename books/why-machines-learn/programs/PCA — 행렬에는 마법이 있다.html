고차원 데이터를 훨씬 적은 수의 축에 투영하되, 데이터가 가장 크게 퍼지는 방향을 고른다. 그 방향의 정체는 공분산 행렬의 고유벡터다. 차원성의 저주를 피하는 가장 강력한 도구를 직접 만져 보자.

MOTIVATION

왜 PCA인가 — 마취 환자의 뇌파

에머리 브라운 연구팀은 마취 중인 사람의 뇌파(EEG)만 보고 의식이 있는지 판별할 수 있는지 알고 싶었다. 전극 하나에서 모은 데이터만 해도 이 정도다.

1전극
100주파수 성분
5,4002초 구간 (3시간)
54만1인당 데이터 점

각 시간 구간은 100차원 공간의 한 점이다. 이대로는 차원성의 저주에 정면으로 걸린다. 그래서 통계학자의 연장통에서 PCA를 빌린다. 데이터를 더 적은 축에 투영하되, 데이터가 가장 많이 변하는 방향을 축으로 고르는 것, 핵심은 그 축의 집합을 제대로 찾는 데 있다.

EXPERIMENT 01

아기 PCA — 어느 축에 투영할까

두 속성 x₁, x₂를 가진 데이터. 동그라미와 세모가 대각선 방향으로 늘어서 있다. 이걸 한 축(1차원)으로 줄이면서도 두 무리가 구분되도록 하고 싶다. 투영 축의 각도를 돌려 보자. 아래 띠는 투영 결과다.

EXPERIMENT 02

행렬 곱, 그리고 고유벡터

행렬 A(m×n)에 벡터 x(n차원)를 곱하면 m차원 벡터 y가 나온다. 행렬의 열 개수와 벡터의 차원이 같아야 곱할 수 있다. 정사각 행렬이면 같은 공간의 한 점을 다른 점으로 옮기는 변환이 된다.

101−2 12 = 1−3

대부분의 벡터는 크기와 방향이 함께 바뀐다. 그런데 어떤 특별한 방향의 벡터는 방향은 그대로(또는 정반대로) 두고 길이만 λ배 된다. 이것이 고유벡터, λ가 고윳값이다.

A x = λ x

‘eigen’은 독일어로 ‘고유한, 특징적인’. 다비트 힐베르트가 1912년 적분방정식에 관한 책에서 Eigenwert(고윳값), Eigenfunktion(고유함수)이라는 말을 썼다.

단위원 위의 벡터들에 행렬을 곱하면 원이 타원으로 찌그러진다. 책 예제 행렬의 고유벡터는 [0, 1](λ = −2)과 [3, 1](λ = 1)이고, 서로 수직이 아니다.

정사각 대칭 행렬(대각선을 기준으로 원소가 대칭)로 바꿔 보자. 고유벡터가 항상 서로 수직이고(직교 고유벡터), 정확히 타원의 장축과 단축 방향을 가리킨다. 고윳값은 실수다. 공분산 행렬이 바로 이런 행렬이라는 게 PCA의 핵심이다.

‘90° 회전’ 행렬은 모든 벡터의 방향을 바꾸므로 실수 고유벡터가 없다(고윳값이 ±i인 복소수).

공분산 행렬 만들기

사람마다 키 h(피트)와 몸무게 w(파운드)를 잰 데이터를 행렬 X로 쓴다. 행 하나가 사람 하나, 열 하나가 속성 하나다.

① 평균 보정(centering). 각 열에서 그 열의 평균을 뺀다. ② XTX 계산. 2×3 행렬과 3×2 행렬의 곱이므로 2×2 정사각 대칭 행렬이 나온다.

책의 두 예에서 비대각 원소는 각각 100과 −40이다. 첫째는 키가 클수록 몸무게도 늘어나는 관계(양의 공분산), 둘째는 키가 커지는데 몸무게가 오히려 줄어드는 관계(음의 공분산)를 포착한다.

단위의 함정 (책 밖 한 걸음). 원자료로는 PC1이 거의 몸무게 축과 같다. 몸무게 숫자가 키보다 훨씬 커서 분산을 독차지하기 때문이다. ‘표준화’를 누르면 각 속성을 표준편차로 나눠 단위를 맞춘다. 그러면 PC1이 ±45° 근처로 돌아가 두 속성의 관계 자체를 반영한다.

엄밀히는 XTX를 n−1(또는 n)로 나눈 것이 공분산 행렬이다. 상수로 나눠도 고유벡터는 그대로이고 고윳값만 같은 비율로 줄어든다.

SUMMARY

PCA 한눈에

  1. 평균 보정. m×n 데이터 행렬 X의 각 열에서 평균을 뺀다.
  2. 공분산 행렬. XTX(n×n, 정사각 대칭 행렬)를 계산한다.
  3. 고유분해. 고윳값과 고유벡터를 구한다. 대칭 행렬이므로 고유벡터는 서로 직교하고, 데이터라는 ‘타원체’의 축 방향을 가리킨다.
  4. 정렬과 선택. 고윳값이 큰 순서대로 고유벡터를 줄 세운다. 고윳값은 그 방향의 분산이다. 위에서 k개만 고른다. 설명 비율은 λᵢ / Σλ.
  5. 투영. 데이터를 고른 k개의 고유벡터에 투영하면 n차원이 k차원으로 줄어든다. 이 축이 주성분이다.

예: 차량 분류

차량마다 높이, 길이, 바퀴 수, 정원, 크기, 형태의 여섯 속성이 있다고 하자. PCA를 하면 첫 주성분은 대체로 ‘크기’ 쪽에 대응할 것이고, 크기와 형태로 대부분의 분산이 설명된다. 그런데 ‘사다리 개수’라는 속성이 더 있다면? 사다리가 있는 차는 소방차뿐이라 이 방향의 분산은 아주 작다. PCA는 이 방향을 버리고, 소방차를 다른 큰 차와 구별할 단서도 함께 사라진다.

분산이 작다 ≠ 중요하지 않다. PCA로 줄인 뒤 버린 방향에 결정적 정보가 있을 수 있다는 위험을 늘 의식해야 한다. 그럼에도 차원을 몇 개로 줄여 계산을 다룰 만하게 만드는 이점이 워낙 크기 때문에 데이터 과학에서 가장 중요한 방법 중 하나로 꼽힌다.

수업용 질문

Q1. A = [[1, 0], [1, −2]]의 고윳값과 고유벡터를 직접 구하라.
det(A − λI) = (1 − λ)(−2 − λ) − 0 = 0 ⇒ λ = 1, −2.
λ = −2: 첫 행 3x₁ = 0 ⇒ x₁ = 0 → [0, 1]. 실제로 A[0, 2] = [0, −4] = −2·[0, 2].
λ = 1: 둘째 행 x₁ − 3x₂ = 0 → [3, 1]. 내적 = 1 ≠ 0이라 직교하지 않는다.
Q2. 대칭 행렬 [[3, 1], [1, 2]]의 고유벡터가 서로 수직임을 확인하라.
λ² − 5λ + 5 = 0 ⇒ λ = (5 ± √5)/2 ≈ 3.618, 1.382.
고유벡터 (1, λ − 3)이므로 (1, (√5−1)/2), (1, (−√5−1)/2). 내적 = 1 + (√5−1)(−√5−1)/4 = 1 − 4/4 = 0. 일반적으로 대칭 행렬의 서로 다른 고윳값에 대응하는 고유벡터는 직교한다(λ₁u·v = Au·v = u·Av = λ₂u·v).
Q3. 평균 보정을 하지 않고 XTX를 계산하면 무엇이 잘못될까?
대각·비대각 원소에 평균값의 제곱과 곱이 섞여 들어가 분산·공분산이 아니게 된다. 그 결과 제1 고유벡터가 ‘데이터가 퍼지는 방향’이 아니라 ‘원점에서 데이터 중심으로 가는 방향’을 가리키게 된다. 실험 03의 원자료 X를 그대로 넣어 비교해 보면 좋다.
Q4. 책 예제 ①의 XTX = [[2, 100], [100, 5066.67]]에서 제1 주성분이 설명하는 분산 비율은?
tr = 5068.67, det = 2·5066.67 − 100² ≈ 133.33 ⇒ λ₁ ≈ 5068.64, λ₂ ≈ 0.026. 비율 ≈ 99.9995%. 이 숫자는 정보가 많아서라기보다 몸무게 단위가 분산을 독차지한 결과다. 표준화하면 λ₁ ≈ 3.987, λ₂ ≈ 0.013 (≈ 99.7%)로 여전히 높지만, PC1이 (0.71, 0.71) 방향으로 바뀐다.
Q5. 고윳값이 ‘그 방향의 분산’이 되는 이유를 단위벡터 u로 설명하라.
평균 보정된 데이터를 단위벡터 u에 투영한 값은 Xu. 그 제곱합은 (Xu)T(Xu) = uT(XTX)u. u가 고윳값 λ의 고유벡터이면 uTλu = λ. 그리고 uTCu를 최대로 만드는 단위벡터가 가장 큰 고윳값의 고유벡터다(실험 01에서 각도를 돌리며 찾은 축).
