퍼셉트론의 답은 하나가 아니다

퍼셉트론은 모든 점을 맞게 나누는 직선을 하나 찾으면 바로 멈춥니다. 시작값과 점을 보는 순서에 따라 매번 다른 직선이 나오죠. 책에서 “분리 초평면이 무한히 많다”고 한 게 이 뜻이에요.

문제는 경계가 한쪽 무리에 바짝 붙어 있으면, 새 점이 조금만 다른 곳에 와도 틀린다는 것(214쪽 그림).

퍼셉트론 경계 SVM 경계 길의 가장자리
SVM의 아이디어: 두 무리 사이에 가장 넓은 길(통로)을 내고, 그 한가운데 선을 경계로 쓴다. 길 가장자리에 딱 걸치는 점(테두리 친 점)이 서포트 벡터.

yi(w·xi + b) ≥ 1은 어디서 나올까?

이 식은 세 조각으로 나눠 보면 쉬워요.

조각 1 · w·x + b의 부호 = 경계의 어느 쪽인가

경계는 w·x + b = 0인 점들이에요. 점을 넣어 계산한 값이 양수면 세모 쪽, 음수면 동그라미 쪽. 값의 크기는 경계에서 멀수록 커집니다(실제 거리는 |w·x + b|‖w‖).

조각 2 · 왜 yi를 곱할까? (두 조건을 한 줄로)

책에서 동그라미는 y = −1, 세모는 y = +1이에요. 맞게 분류되려면:

점yi원하는 w·x + b둘을 곱하면
세모+1양수양수
동그라미−1음수양수
잘못된 쪽±1반대 부호음수

즉 “곱이 양수 = 맞게 분류됨”. 세모용 식, 동그라미용 식을 따로 쓰지 않으려는 요령이에요. 퍼셉트론은 여기까지, 곱 > 0만 요구합니다.

조각 3 · 그런데 왜 0이 아니라 1일까?

핵심은 같은 직선을 쓰는 방법이 무수히 많다는 거예요. 2x − y + 1 = 0과 4x − 2y + 2 = 0은 똑같은 직선이죠. w와 b에 같은 수를 곱해도 경계는 그대로인데, 점마다 계산되는 값의 크기만 바뀝니다.

아래 슬라이더로 w, b에 곱하는 수 k를 바꿔 보세요. 검은 경계선은 꿈쩍 안 하는데, 점 옆의 숫자 yi(w·xi + b)가 전부 같이 커지고 작아져요. 점을 누르면 계산 과정이 나와요.

경계 (값 = 0) 값 = +1, −1 인 선
그래서 ≥ 1
  1. 크기를 마음대로 바꿀 수 있으니 “가장 가까운 점에서 값이 딱 1”이 되도록 눈금을 정한다. (1은 약속일 뿐. 5로 정해도 경계는 같고 w, b만 5배가 됨)
  2. 그러면 ≥ 1 = “모든 점이 가장 가까운 점만큼은 떨어져 있다” = 길 안에 점이 하나도 없다.
  3. 만약 > 0만 요구하고 ‖w‖를 줄이면? 부호는 안 바뀌니 w를 0까지 계속 줄여도 OK → 의미 없는 답. ‘1’이라는 기준을 박아 둬야 ‖w‖ 줄이기가 길 넓히기가 됩니다(다음 탭).

길의 폭은 2‖w‖, 그래서 ‖w‖를 줄인다

앞 탭의 약속대로 길 가장자리를 w·x + b = ±1로 정하면 길의 폭 = 2‖w‖. ‖w‖가 작을수록 길이 넓어져요.

슬라이더로 ‖w‖를 줄여 보세요. 길이 넓어지다가, 너무 줄이면 점이 길 안으로 들어와 제약(≥ 1)이 깨집니다.

정리: “모든 점이 ≥ 1을 지키는 범위 안에서 ‖w‖를 가장 작게” = 마진 최대화. 책이 ‖w‖ 대신 ‖w‖22을 쓰는 건, 답은 똑같으면서 매끈한 2차함수(그릇 모양)라 미분·계산이 편해서예요.
왜 w는 경계에 수직이고, 폭은 2‖w‖일까?

수직인 이유: 경계 위의 두 점 p, q는 w·p + b = 0, w·q + b = 0. 빼면 w·(p − q) = 0. 경계 방향과 w의 내적이 0이니 수직.

폭: 경계 위 점 p에서 w 방향(단위벡터)으로 거리 t만큼 가서 가장자리 w·x + b = 1에 닿는다면

w·p + b + t‖w‖ = 1  ⇒  t = 1‖w‖

반대쪽도 똑같으니 전체 폭은 2‖w‖.

그릇 바닥만이 아니다

제약이 없으면 최솟값 찾기는 “경사를 따라 바닥으로 내려가기”예요. 그런데 책의 비유처럼 정해진 원 모양 길 위에서만 움직여야 한다면? 답은 바닥이 아니라 그 길 위에서 가장 낮은 곳이 됩니다.

그림을 손가락으로 끌면 돌아가요. 점선 원 = 바닥 평면 위의 제약 x2 + y2 = r2, 보라 곡선 = 그 원을 따라 곡면 위를 걸을 때의 경로.

원 위의 길 지금 위치 길 위 최저점 제약 없을 때 바닥·안장점

원을 한 바퀴 돌 때의 높이:

SVM에서는: 그릇 = ‖w‖22, 바닥 = w = 0. 그런데 w = 0이면 ≥ 1을 지킬 수 없으니 바닥엔 못 간다. 그래서 “제약을 지키는 영역 안에서 가장 낮은 곳”을 찾아야 하고, 이게 책의 제약하 최적화 문제예요.

극값은 등고선이 길에 ‘접하는’ 곳

앞 탭의 말안장 f(x, y) = xy + 30을 위에서 내려다본 지도예요. 주황은 높은 곳, 파랑은 낮은 곳, 얇은 선은 등고선. 제약은 반지름 2인 원 x2 + y2 = 4. 원 위의 점을 끌어 보세요.

지금 점을 지나는 등고선 ∇f (가장 가파르게 오르는 방향) ∇g (원에 수직인 방향)

원을 한 바퀴 돌 때의 높이 f:

핵심: 등고선이 원을 가로지르면 원을 따라 조금만 가도 높이가 변하니 극값이 아니다. 극값은 등고선이 원에 딱 접하는 곳. 접한다 = 두 곡선의 수직 방향(그래디언트)이 평행하다는 뜻이고, 식으로 쓰면 ∇f = λ ∇g 이게 라그랑주 승수법의 출발점이에요.
직접 풀어보기: 원 위에서 xy + 30의 최대·최소

g(x, y) = x2 + y2라 하면 ∇f = (y, x), ∇g = (2x, 2y).

  1. ∇f = λ∇g → y = 2λx, x = 2λy
  2. 대입하면 x = 4λ2x → λ = ±12
  3. λ = 12이면 y = x, λ = −12이면 y = −x
  4. 원에 대입: 2x2 = 4 → x = ±√2

→ (√2, √2), (−√2, −√2)에서 최댓값 32, (√2, −√2), (−√2, √2)에서 최솟값 28.

한 줄씩 정리

1. 퍼셉트론은 아무 분리선이나 찾고 멈춘다 → 새 점에 약하다.
2. SVM은 두 무리 사이 가장 넓은 길의 한가운데를 경계로 쓴다.
3. 길 가장자리를 w·x + b = ±1로 약속 → 모든 점이 길 밖: yi(w·xi + b) ≥ 1
4. 길 폭 = 2‖w‖ → 폭 최대 = ‖w‖ 최소 = ‖w‖22 최소
5. 그릇의 바닥(w = 0)은 제약 때문에 못 감 → 제약하 최적화
6. 제약 위 극값 = 등고선이 제약에 접하는 곳 → ∇f = λ∇g (라그랑주)

SVM은 원 예제의 큰 버전이에요. 최소화할 함수는 ‖w‖22, 제약은 원 하나 대신 데이터 점마다 하나씩, 그리고 등식이 아니라 부등식.

책 뒷부분에서 이어질 내용: 이렇게 라그랑주 방식으로 풀면 경계가 서포트 벡터들만으로 정해지고, 계산에 데이터 점끼리의 내적만 등장해요. 장 제목의 ‘커널’이 거기서 나옵니다.
