수렴 증명 실험실

STEP 1 / 5 · 증명의 무대 세우기

무엇을 가정하고, 무엇을 증명할까

증명하려는 것은 한 문장이다. 데이터를 초평면으로 나눌 수 있으면, 퍼셉트론은 유한한 횟수만 고치고 반드시 멈춘다. 계산이 깔끔해지도록 세 가지를 약속하고 시작한다.

기호뜻약속
w*데이터를 완벽히 나누는 정답 가중치길이를 1로 맞춘다 (‖w*‖ = 1)
x데이터 점 (벡터)가장 먼 점의 길이가 1이 되도록 전체를 같은 비율로 줄인다 (‖x‖ ≤ 1)
y정답 라벨+1 또는 −1
γ (감마)초평면에서 가장 가까운 점까지의 거리0 < γ ≤ 1
w훈련 중인 가중치0에서 출발, 틀리면 w ← w + y·x
M지금까지 고친 횟수이 값이 유한함을 보이는 것이 목표

전체를 같은 비율로 줄여도 점들 사이의 관계와 방향은 그대로다. 편향은 가중치 벡터 안에 넣었다고 보고, 초평면은 원점을 지나는 것으로 그린다.

y·w*ᵀx가 ‘거리’인 이유

w*의 길이가 1이므로 w*ᵀx는 x를 w* 방향으로 비춘 그림자의 길이다. 그것이 곧 초평면에서 x까지의 거리다. w*는 모든 점을 맞히므로 y를 곱하면 항상 양수가 된다. 그 가운데 가장 작은 값이 γ다. 그래서 모든 점에서 y·w*ᵀx ≥ γ다.

STEP 2 / 5 · 중간 결과 1

wᵀw*는 고칠 때마다 γ 이상 커진다

w가 w*와 같은 쪽을 향할수록 점곱 wᵀw*가 커진다. 한 번 고친 뒤 이 값이 어떻게 변하는지 전개해 보자.

전개

w(새)ᵀw* = (w(옛) + y·x)ᵀw* = w(옛)ᵀw* + y·xᵀw*

점곱은 순서를 바꿔도 같으므로 y·xᵀw* = y·w*ᵀx이고, STEP 1에서 본 대로 이 값은 γ 이상이다.

w(새)ᵀw* ≥ w(옛)ᵀw* + γ

0에서 출발해 M번 고쳤다면 γ가 M번 쌓인다.  M·γ ≤ wᵀw* … (1)

M고친 점늘어난 양 y·w*ᵀx≥ γ ?wᵀw*M·γ

STEP 3 / 5 · 중간 결과 2

wᵀw는 고칠 때마다 많아야 1 커진다

그런데 wᵀw*는 w가 그냥 길어지기만 해도 커진다. 방향이 맞아서 커진 것인지 확인하려면 w 자신의 길이 제곱 wᵀw = ‖w‖²가 얼마나 빨리 자라는지도 봐야 한다.

전개

w(새)ᵀw(새) = (w(옛) + y·x)ᵀ(w(옛) + y·x)

= w(옛)ᵀw(옛) + 2y·w(옛)ᵀx + y²·xᵀx

가운데 항 ≤ 0: 틀린 점에서만 고치므로 y·w(옛)ᵀx ≤ 0이다.
마지막 항 ≤ 1: y² = 1이고, 정규화했으므로 xᵀx = ‖x‖² ≤ 1이다.

w(새)ᵀw(새) ≤ w(옛)ᵀw(옛) + 1

0에서 출발해 M번 고쳤다면  wᵀw ≤ M … (2)

M2y·wᵀx (≤ 0)xᵀx (≤ 1)늘어난 양wᵀw≤ M ?

STEP 4 / 5 · 두 결과를 합치기

M·γ ≤ √M, 그래서 M ≤ 1/γ²

마지막 연결

wᵀw* = ‖w‖‖w*‖cos θ ≤ ‖w‖   (‖w*‖ = 1, cos θ ≤ 1)

‖w‖ = √(wᵀw) ≤ √M   (결과 2)

M·γ ≤ wᵀw* ≤ ‖w‖ ≤ √M   (결과 1과 연결)

M²γ² ≤ M  →  M ≤ 1/γ²

γ는 0보다 큰 수이므로 1/γ²은 유한하다. 고치는 횟수 M이 이 값을 넘을 수 없으니 훈련은 반드시 멈춘다. 증명 끝.

틈이 좁아지면 상한은 어떻게 될까?

틈γ상한 1/γ²실제 갱신 M

γ가 절반이 되면 상한은 4배가 된다. 두 무리가 가까울수록 어려운 문제다. 그래도 γ > 0이기만 하면 상한은 유한하다.

STEP 5 / 5 · 정리

증명을 네 줄로

한눈에 정리
  1. 가정: ‖w*‖ = 1, 모든 점에서 ‖x‖ ≤ 1, 초평면에서 가장 가까운 점까지 거리 γ > 0, w는 0에서 출발.
  2. 결과 1: 고칠 때마다 wᵀw*는 γ 이상 커진다. → M·γ ≤ wᵀw*
  3. 결과 2: 고칠 때마다 wᵀw는 많아야 1 커진다. → wᵀw ≤ M
  4. 결론: M·γ ≤ wᵀw* ≤ ‖w‖ ≤ √M 이므로 M ≤ 1/γ². 선형 분리 가능한 데이터에서 퍼셉트론은 유한 번 만에 멈춘다.

증명의 뼈대

같은 값을 아래에서 받치는 식(빠르게 자람)과 위에서 누르는 식(느리게 자람) 사이에 끼워 넣었다. 둘이 엇갈리는 지점보다 더 멀리 갈 수 없다는 것이 핵심이다. 수학에서 자주 쓰는 ‘샌드위치’ 논법이다.

Q1

결과 1의 전개에서 y·xᵀw* = y·w*ᵀx로 바꿀 수 있는 이유는?

답 보기
두 벡터의 점곱은 순서와 상관없다. a = (a1, a2), b = (b1, b2)이면 aᵀb = a1b1 + a2b2 = bᵀa이다.
Q2

결과 2에서 가운데 항 2y·wᵀx가 0 이하라는 사실은 알고리즘의 어느 부분에서 나올까?

답 보기
퍼셉트론은 y·wᵀx ≤ 0인 점(틀린 점)에서만 w를 고친다. 그래서 고치는 순간의 y·wᵀx는 언제나 0 이하다. 맞힌 점에서는 고치지 않으니 이 식을 쓸 일이 없다.
Q3

M·γ ≤ √M에서 M ≤ 1/γ²을 유도해 보자. 제곱해도 부등호 방향이 유지되는 이유도 말해 보자.

답 보기
양변이 모두 0 이상이므로 제곱해도 부등호 방향이 그대로다. M²γ² ≤ M이고, M > 0으로 나누면 Mγ² ≤ 1, 즉 M ≤ 1/γ²이다.
Q4

γ = 0.1인 데이터라면 퍼셉트론은 최대 몇 번 고칠까? γ = 0.01이라면?

답 보기
1/0.1² = 100번 이하, 1/0.01² = 10,000번 이하다. γ가 10분의 1이 되면 상한은 100배가 된다.
Q5

데이터를 정규화하지 않고, 가장 먼 점의 길이를 R이라고 두면 결과 2와 결론은 어떻게 바뀔까?

답 보기
xᵀx ≤ R²이므로 결과 2는 wᵀw ≤ M·R²이 된다. 그러면 M·γ ≤ √M·R이고 M ≤ R²/γ²이다. 정규화는 R = 1로 만들어 식을 간단하게 하는 장치다.
Q6

나눌 수 없는 데이터에서는 이 증명의 어느 가정이 무너질까?

답 보기
모든 점을 맞히는 w*가 없으므로 γ > 0을 보장할 수 없다. 결과 1(매번 γ 이상 증가)을 쓸 수 없어서 상한이 생기지 않는다.

나만의 질문 1개 · 상한 1/γ²은 실제 갱신 횟수보다 훨씬 클 때가 많다. 그런데도 이 증명이 가치 있는 이유를 한 문장으로 써 보자.
