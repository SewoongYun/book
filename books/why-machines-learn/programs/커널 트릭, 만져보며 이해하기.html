커널 트릭, 만져보며 이해하기

2차원에서 못 나누면, 한 층 올려라

가운데에 동그라미, 둘레에 세모. 직선 하나로는 절대 나눌 수 없어요(선형 분리 불가). 퍼셉트론도, 앞 장의 SVM도 직선(초평면)만 그을 줄 알죠.

책(233쪽)의 해법: 점마다 세 번째 속성 z = x12 + x22을 계산해서 그 높이만큼 들어올리기. 원점에서 먼 세모는 높이, 가까운 동그라미는 낮게 올라가요.

데이터

세 번째 속성 z

그림을 손가락으로 끌면 돌아가요

③ 위에서 내려다보면 (2차원으로 되돌리면):

평면 z = c가 2차원에 남긴 경계 잘못 나뉜 점
핵심: 3차원에서는 평평한 평면 z = c로 잘랐을 뿐인데, 2차원으로 돌아오면 원 x12 + x22 = c가 됩니다. 고차원의 직선적 경계 = 원래 공간의 휘어진 경계.
그런데 ‘섞인 데이터’는요?

233쪽 아래 그림처럼 섞여 있으면 x12 + x22로 들어올려도 안 나뉘어요. 직접 데이터를 바꿔 보세요. 대신 z = x1x2로 들어올리면 됩니다.

즉 데이터마다 필요한 속성이 다르다는 것. “그럼 x12, x22, x1x2, x1, x2, … 다 넣으면 되지 않나?” → 그러면 차원이 폭발하고 계산이 감당 안 됩니다. 이게 다음 탭의 문제예요.

φ: 점을 고차원으로 보내는 대응

점 x를 고차원 점 φ(x)로 보내는 규칙을 대응(사상)이라고 해요. 책(234쪽)의 예:

[x1, x2] → φ(x) = [x12, x22, √2 x1x2]

앞 장에서 봤듯 SVM(그리고 퍼셉트론)은 계산 중에 데이터를 점끼리의 내적 형태로만 써요. 그러니 고차원에서 알고리즘을 돌리려면 φ(a)·φ(b)만 구할 수 있으면 됩니다.

두 화살표 끝을 끌어 보세요. 두 가지 방법으로 계산한 값이 항상 같아요.

놀라운 점: 3차원으로 가서 내적한 값 = 2차원 내적을 제곱한 값. φ(a)·φ(b) = (a·b)2 = K(a, b) 고차원 좌표를 한 번도 만들지 않고, 원래 공간에서 계산해 고차원 내적을 얻는 함수 K를 커널 함수라고 불러요.
왜 하필 √2일까?

(a·b)2 = (a1b1 + a2b2)2 = a12b12 + a22b22 + 2a1a2b1b2

세 번째 항의 계수 2를 φ(a)와 φ(b)가 반씩 나눠 가지려면 각자 √2를 가져야 해요. √2 × √2 = 2. 위의 버튼으로 √2를 빼면 값이 어긋나는 걸 확인할 수 있어요.

커널 트릭: 고차원에 가지 않고 고차원 내적 구하기

2차원 → 3차원이면 직접 계산해도 별 차이 없죠. 그런데 원래 데이터가 n차원이고 다항 커널 (1 + x·y)d을 쓰면, 대응된 공간의 차원은

D = (n + d)!d! n!

(240쪽의 공식, 다음 탭에서 직접 세어 봐요)

대응된 공간의 차원 D
내적 한 번의 곱셈 횟수
커널 트릭 (236쪽): 알고리즘 안의 모든 내적 xi·xj를 K(xi, xj)로 바꿔치기. 그러면 알고리즘은 고차원에서 돈 것과 똑같은 결과를 내는데, 계산은 원래 차원에서만 해요. 고차원 좌표는 한 번도 만들지 않습니다.

다항 커널 K(x, y) = (c + x·y)d

포조가 1975년에 도입한 일반형이에요(238쪽). c = 0, d = 2면 2탭의 커널, c = 1, d = 2면 책 239쪽의 예. 2차원 점 [x1, x2]에 대해 이 커널이 몰래 쓰고 있는 φ를 펼쳐 봅니다.

φ의 성분은 어떻게 찾았나? (전개해 보기)

(c + a1b1 + a2b2)d을 다항정리로 펼치면 항마다

d!k0! k1! k2! ck0 (a1b1)k1 (a2b2)k2

(단, k0 + k1 + k2 = d). 이 계수를 a 쪽과 b 쪽이 √씩 나눠 가지면 φ의 한 성분 √(계수) · x1k1x2k2이 돼요. 2탭의 √2와 같은 원리예요.

성분 개수 = k0 + k1 + k2 = d의 음이 아닌 정수해 개수 = n+1Hd = (n + d)!d! n!. 확률과 통계의 중복조합이에요! 단 c = 0이면 k0 > 0인 항이 모두 0이라 d + 1개(2차원일 때)로 줄어요.

커널 퍼셉트론 vs 커널 SVM

같은 커널을 써도 고차원에서 어떤 초평면을 고르냐에 따라 2차원 경계가 달라져요. 책(242–243쪽): 퍼셉트론의 경계는 동그라미에 너무 바짝 붙어 새 점을 틀리기 쉽고, 최적 마진(SVM)을 쓰면 가운데를 지나는 경계를 얻어요.

해 볼 것
  1. 다항 커널로 퍼셉트론을 여러 번 → 매번 다른 타원, 동그라미에 바짝 붙기도.
  2. SVM → 두 무리 한가운데를 지나는 경계(책의 원 모양).
  3. 선형 커널 → 원래 2차원 그대로라 아무리 돌려도 실패.
  4. 섞인 데이터 + 다항 커널 → φ 안에 √2x1x2가 들어 있어 나뉨!

RBF 커널: 무한 차원으로 가는 커널

K(a, b) = exp(−γ‖a − b‖2),   γ > 0

방사형 기저 함수(RBF) 커널은 대응된 공간이 무한 차원이에요(243쪽). φ를 실제로 만드는 건 불가능하지만, K는 거리만 알면 바로 계산됩니다. 커널 트릭이 없으면 아예 쓸 수 없는 커널이죠.

K는 두 점이 얼마나 닮았나(가까운가)를 0~1로 재요. 같은 점이면 1, 멀어지면 0. 두 점을 끌어 보세요.

거리에 따른 K (흐린 선은 γ = 1):

왜 무한 차원일까?

‖a − b‖2 = ‖a‖2 + ‖b‖2 − 2a·b이므로

K = e−γ‖a‖² · e−γ‖b‖² · e2γ a·b

마지막 부분을 et의 테일러 전개로 펼치면

e2γa·b = 1 + (2γa·b) + (2γa·b)22! + (2γa·b)33! + ⋯

각 항 (a·b)k은 차수 k인 다항 커널이고, 각자 자기만의 φ 성분들을 필요로 해요(4탭). 차수 1, 2, 3, …이 끝없이 더해지니 φ의 성분도 끝이 없어요. 그래서 무한 차원(힐베르트 공간).

γ의 의미: γ가 크면 아주 가까운 점끼리만 닮았다고 봐서 경계가 점 하나하나를 감싸며 구불구불해져요(과적합). 작으면 경계가 부드러워요. 실험실에서 γ를 바꿔 보세요.

한 줄씩 정리

1. 2차원에서 직선으로 못 나누는 데이터도 새 속성으로 한 층 올리면 평면으로 나뉠 수 있다.
2. 고차원의 평평한 경계를 원래 공간에 되돌리면 휘어진 경계(원, 타원, 쌍곡선…)가 된다.
3. 퍼셉트론·SVM은 데이터를 내적으로만 쓴다 → 필요한 건 φ(a)·φ(b)뿐.
4. φ(a)·φ(b) = K(a, b)인 커널 함수가 있으면 고차원 좌표를 만들 필요가 없다 = 커널 트릭.
5. 다항 커널 (c + x·y)d의 차원은 (n + d)!d! n! (중복조합), RBF 커널은 무한 차원.
6. 커널 + 최적 마진 분류자 = 서포트 벡터 머신. 경계가 가운데를 지나 새 점에 강하다.

이 장의 이야기

1964 · 아이제르만, 브라베르만, 로조노에르(러시아)가 커널 아이디어를 담은 논문을 씀.
1975 · MIT의 포조가 다항 커널의 일반형을 도입.
1991 가을 · 보저가 바프니크의 최적 마진 분류자를 구현. 귀용이 커널을 붙이자고 제안 → 고차원에 직접 가지 않는 SVM 탄생.

생각해 볼 질문

Q1. 3차원에서 평면 z = c로 나눴는데, 2차원에선 왜 원이 될까?

평면 위의 점은 z = c인데 z = x12 + x22이니까, 원래 좌표로 쓰면 x12 + x22 = c. 반지름 √c인 원이에요. 평면이 기울어 있었다면(z = px1 + qx2 + c) 중심이 옮겨진 원이 되고요.

Q2. 커널 퍼셉트론과 커널 SVM은 같은 커널을 쓰는데 왜 경계가 다를까?

같은 고차원 공간에서 어떤 초평면을 고르냐가 다르기 때문이에요. 퍼셉트론은 다 맞히는 아무 초평면에서 멈추고, SVM은 가장 넓은 길의 한가운데를 고릅니다. 앞 장 1탭의 이야기가 고차원에서 그대로 반복되는 거예요.

Q3. 원래 데이터가 784차원(28×28 이미지)이고 d = 3이면 φ는 몇 차원?

787!3! 784! = 787 × 786 × 7856 = 80,931,145, 약 8,093만 차원. 점 하나를 저장하는 데만 약 620 MB가 들어요. 커널을 쓰면 784번 곱하고 세제곱하면 끝(3탭에서 확인).
