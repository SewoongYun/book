STEP 3 / 6 · 편도함수

변수가 둘이면, 기울기도 둘

그릇 z = x² + y² 위의 한 점에 서 있다. 이제 움직일 수 있는 방향이 x와 y 두 가지다. 한 변수만 움직이고 나머지는 그대로 둔 채 잰 기울기를 편도함수라고 한다.

4
∂z/∂x = 2x6
∂z/∂y = 2y8
기울기 벡터[6, 8]
두 편도함수를 묶은 [∂z/∂x, ∂z/∂y]가 기울기(벡터)다. 크기와 방향이 있는 화살표 하나로 “어느 쪽이 가장 가파른 오르막인지”를 알려 준다.

기울기 [6, 8]은 바닥 반대쪽을 가리킨다. 그래서 반대 방향 [−6, −8] 쪽으로 한 걸음.

변수가 셋이면? 그릴 수는 없어도 계산은 된다

f(x, y, z) = x² + 3y³ + z⁵ 변수 3개 + 함숫값 = 4차원이라 그림으로 볼 수 없다
편도함수구하는 법결과
∂f/∂xy, z는 상수 취급 → x²만 미분2x
∂f/∂yx, z는 상수 취급 → 3y³만 미분9y²
∂f/∂zx, y는 상수 취급 → z⁵만 미분5z⁴
x y z

이 점에서의 기울기 [2x, 9y², 5z⁴] = [2, 36, 5]

숫자를 바꿔 보자. 변수가 몇 개든 같은 방법으로 기울기를 구한다.

반대 방향으로 한 걸음: 좌표가 실제로 어떻게 바뀔까

새 위치 = 지금 위치 − η × 기울기 x, y, z 각각에 같은 규칙을 따로 적용한다

더

y = x²에서 xnew = x − η·2x를 정리하면 xnew = (□) · x 꼴이 된다. □는?

풀이 보기
xnew = (1 − 2η) · x. 한 걸음마다 x에 같은 수 (1 − 2η)를 곱하는 등비수열이다. η = 0.1이면 0.8씩 곱해져 1, 0.8, 0.64, 0.512, …
더

공이 바닥(x = 0)에 가까워지려면 η는 어떤 범위여야 할까? η = 0.5, η = 1이면?

풀이 보기
|1 − 2η| < 1 → 0 < η < 1.
η = 0.5: 1 − 2η = 0이라 한 걸음에 바로 바닥.
η = 1: 1 − 2η = −1이라 1, −1, 1, −1… 영원히 왕복.
η > 1: |1 − 2η| > 1이라 점점 멀어진다.

STEP 6 / 6 · 정리하기

기울기를 거슬러, 조금씩

오늘의 정리

경사 하강법은 기울기의 반대 방향으로 η만큼 조금씩 움직이기를 반복해 바닥(최솟값)을 찾는다.

바닥이 어디인지 몰라도, 지금 자리의 기울기만 알면 된다. 바닥에 가까워질수록 기울기가 작아져 걸음도 저절로 작아진다.

걸음 크기 η

너무 작으면 느리고, 너무 크면 바닥을 지나쳐 튕겨 나간다.

y = x²에서는 0 < η < 1이어야 수렴

편도함수

변수가 여러 개면 하나씩만 움직였을 때의 기울기를 따로 구한다.

z = x² + y² → ∂z/∂x = 2x, ∂z/∂y = 2y

전역 · 지역 최솟값

그릇 전체에서 가장 낮은 곳이 전역, 움푹한 곳마다 있는 바닥이 지역 최솟값이다.

바닥이 여러 개면 출발점에 따라 도착지가 달라진다

안장점

기울기가 0인데 최솟값이 아닌 점. 한쪽은 오목, 다른 쪽은 볼록하다.

z = y² − x²의 (0, 0)

STEP 1 내 예상: 아직 고르지 않음

Q1

안장 표면에서 x = 0인 능선 위 정확히 출발하면 공은 어디서 멈출까? x를 0.1만 벗어나면?

생각할 거리
x = 0이면 ∂z/∂x = −2x = 0이라 x는 영원히 0이고, y만 줄어 안장점 (0, 0)에 멈춘다. 기울기가 0이니 바닥인 줄 착각하는 셈이다. x가 조금만 0이 아니어도 xnew = (1 + 2η)x로 점점 커져 옆으로 굴러떨어진다.
Q2

인공지능이 ‘학습한다’는 것과 경사 하강법은 어떤 관계일까?

생각할 거리
기계 학습에서는 예측이 얼마나 틀렸는지를 나타내는 오차 함수를 만들고, 그 값이 가장 작아지는 매개변수를 찾는다. 오차 함수가 곧 ‘그릇’이고, 경사 하강법은 그 바닥으로 내려가는 방법이다. 변수가 수백만 개여도 원리는 같다.
Q3

바닥이 두 개인 그릇에서 경사 하강법을 쓰면 어떤 문제가 생길 수 있을까? 해결 아이디어는?

생각할 거리
출발점 근처의 지역 최솟값에 갇혀 더 낮은 전역 최솟값을 놓칠 수 있다. 여러 출발점에서 굴려 보거나, 걸음 크기를 바꿔 가며 시도하는 방법이 있다.
