인공 뉴런 실험실

STEP 1 / 6 · 신경세포에서 뉴로드로

뇌세포 하나를 아주 단순한 계산기로 바꾸면?

1943년, 신경과학자 매컬러와 10대 수학 천재 피츠는 신경세포가 하는 일을 ‘켜짐(1)’과 ‘꺼짐(0)’만으로 흉내 내는 계산 모형을 만들었다.

이 인공 신경세포를 뉴로드(neurode = neuron 신경세포 + node 분기점)라고 부른다.

신경세포뉴로드하는 일
가지돌기입력 x1, x2다른 세포에서 오는 신호를 받는다. 신호는 0 또는 1뿐이다.
세포체g와 f받은 신호를 모두 더하고(g), 합이 기준 θ를 넘는지 판정한다(f).
축삭돌기·말단출력 y판정 결과(0 또는 1)를 다음 세포로 보낸다.

“입력을 더한 뒤 합이 임곗값 θ(세타)보다 크거나 같은지 검사하면 된다.”

23~24쪽

예상해 보자: 0과 1만 다루는 이 단순한 장치로 무엇을 할 수 있을까?

고른 답은 STEP 6에서 다시 확인한다.

STEP 2 / 6 · AND·OR 만들기

θ 하나만 바꿨을 뿐인데 기능이 바뀐다

입력 스위치를 켜고 끄면서 θ를 바꿔 보자. 표가 어떤 규칙이 되는지 보고, 그 규칙의 이름을 맞혀 본다.

뉴로드의 계산 규칙 (24쪽)

① 더하기g(x) = x1 + x2

② 판정하기f(z) = 0,  z < θ1,  z ≥ θ

③ 출력y = f(g(x))  ← 합성함수!

임곗값 θ

θ = 2일 때의 진리표  AND

x1x2합 g출력 y

AND (θ = 2) · 둘 다 1이어야 1

금고 열쇠 2개를 모두 꽂아야 열린다. 회로로는 스위치를 한 줄로 이은 직렬 연결이다.

OR (θ = 1) · 하나만 1이어도 1

자동문은 안쪽·바깥쪽 센서 중 하나만 감지해도 열린다. 회로로는 길이 두 갈래인 병렬 연결이다.

θ는 ‘얼마나 깐깐하게 켜 줄지’를 정하는 기준!

STEP 3 / 6 · 억제성 입력과 NOT

“안 돼!”라고 말하는 입력

25쪽에서는 입력을 억제성(inhibitory)으로 만들 수 있다고 한다. 억제성 입력은 더하기 전에 −1을 곱한다. 그래서 이 입력이 1이면 합이 오히려 1 줄어든다.

학교 출입 게이트를 떠올려 보자. 학생증을 찍으면(흥분성 입력) 문이 열린다.

STEP 4 / 6 · XOR과 정리

뉴로드 하나로는 끝내 못 만드는 것

XOR(배타적 OR)은 두 입력이 서로 다를 때만 1이 된다. 계단 조명 스위치가 대표적인 예다. 1층과 2층 스위치 상태가 다르면 불이 켜지고, 같으면 꺼진다. 23쪽에서는 XOR을 만들려면 뉴로드가 둘 이상 필요하다고 했다. 정말인지 직접 도전해 보자.

도전: 뉴로드 하나로 XOR 만들기

θ
x1x2합 g뉴로드 yXOR 목표일치?

뉴로드 하나는 “합 ≥ θ면 켜기”라는 기준선 하나만 긋는다. 기준선 오른쪽은 모두 켜지고 왼쪽은 모두 꺼진다. 그래서 가운데만 켜고 양 끝은 끄는 XOR은 만들 수 없다.

해결: 뉴로드 3개를 이어 붙이기

XOR = (x1 OR x2) 그리고 NOT (x1 AND x2). OR 뉴로드와 AND 뉴로드의 결과를 세 번째 뉴로드에 넣는다. 이때 AND 쪽은 억제성(−1)으로 넣는다.

MCP 뉴로드의 한계 (25쪽)

MCP 뉴로드를 잘 짜 맞추면 어떤 디지털 연산이든 할 수 있다. 하지만 AND는 θ = 2, OR은 θ = 1처럼 θ를 사람이 직접 정해야 했다. 데이터를 보고 스스로 θ를 찾아내지는 못했다. 즉, 학습할 수 없었다.

스스로 값을 찾는 뉴런이 나오기까지는 15년이 더 걸렸다. 그게 다음 STEP의 퍼셉트론이다.

STEP 5 / 6 · 퍼셉트론

MCP 뉴로드를 업그레이드하면: 퍼셉트론

1950년대 후반, 프랭크 로젠블랫은 MCP 뉴로드를 고쳐서 퍼셉트론을 만들었다.

20×20픽셀 카메라를 단 ‘퍼셉트론 1호’는 글자를 보고 알파벳을 알아맞혔다. 실수를 하면 그때마다 고쳐 가며 맞히는 법을 배웠다.

MCP 뉴로드 (STEP 1~4)퍼셉트론
입력0 또는 1만어떤 값이든 (키 172, 몸무게 65.5 …)
입력 처리그냥 더한다입력마다 가중치 w를 곱해서 더한다 (가중합)
기준합 ≥ θ 인가?편향 b를 더한 뒤 합 > 0 인가?

퍼셉트론의 계산 규칙 (29쪽)

① 가중합g(x) = w1·x1 + w2·x2 + … + wn·xn + b = Σ wi·xi + b

② 판정하기f(z) = −1,  z ≤ 0 1,  z > 0

③ 출력y = f(g(x))

θ는 어디로 갔을까? → 편향 b가 되었다

MCP의 조건 “합 ≥ θ”에서 θ를 왼쪽으로 넘기면 “합 − θ ≥ 0”이 된다. 이 −θ가 편향 b 역할을 한다. 그래서 퍼셉트론은 기준값 없이 “0보다 큰가?”만 보면 된다. 책의 퍼셉트론은 0 초과일 때 +1이므로, θ = 2인 AND는 b를 −2보다 조금 큰 −1.5 정도로 두면 된다.

STEP 6 / 6 · 퍼셉트론의 학습

틀리면서 배운다: 키와 몸무게로 비만 분류하기

30쪽의 예를 따라가 보자. 몸무게 x1과 키 x2를 보고 비만(y = +1, ●)인지 비만 아님(y = −1, ▲)인지 분류한다. 퍼셉트론은 w1 = w2 = b = 0에서 출발한다. 데이터를 하나씩 보면서 틀릴 때마다 w1, w2, b를 고친다.

학습 규칙 · 틀린 점을 만나면 선을 그 점 쪽으로 옮긴다

맞히면아무것도 바꾸지 않는다

틀리면w1 ← w1 + y·x1,  w2 ← w2 + y·x2,  b ← b + y

y는 그 점의 정답(+1 또는 −1)이다. 계산할 때는 몸무게와 키를 100으로 나눈 값을 쓴다. 이 규칙이 왜 통하는지는 책 뒤에서 자세히 나온다.

확인한 데이터0
고친 횟수0
바퀴0
틀린 점20

‘한 명씩 확인’을 눌러 학습을 시작하자.

조정 과정 계산판 방금 확인한 사람의 계산이 그대로 나온다

처음 몇 명은 ‘한 명씩 확인’으로 천천히 보자. #1은 틀려서 고친 뒤 바로 맞게 된다. #2는 고쳐도 아직 틀린다.

왜 이런 공식일까?
  1. 맞힘을 식으로 쓰기 · 정답 y와 가중합 z의 부호가 같으면 맞힌 것이다. 즉 y·z > 0이면 맞고, y·z ≤ 0이면 틀린다.
  2. 고친 뒤의 가중합 · w1 + y·x1, w2 + y·x2, b + y를 넣으면
    z′ = (w1 + y·x1)·x1 + (w2 + y·x2)·x2 + (b + y) = z + y·(x1² + x2² + 1)
  3. 양변에 y를 곱하기 · y² = 1이므로 y·z′ = y·z + (x1² + x2² + 1)이다. 괄호 안은 제곱의 합에 1을 더한 값이라 항상 양수다. 그래서 고칠 때마다 y·z가 반드시 커진다. 즉 그 점의 판정이 정답 쪽으로 움직인다.
  4. 왜 x를 곱할까? · 값이 큰 입력은 판정에 더 큰 영향을 주었다. 그러니 그 입력의 가중치를 더 많이 고친다. 입력이 0이었다면 책임이 없으니 그 가중치는 바뀌지 않는다. 편향 b는 ‘항상 1인 입력’의 가중치로 보면 같은 규칙(b ← b + y·1)이다.
  5. 언젠가 끝날까? · #2처럼 한 번에 다 고쳐지지 않을 때도 있다. 그래도 데이터가 직선 하나로 나뉘기만 하면 정해진 횟수 안에 반드시 학습이 끝난다는 사실이 수학적으로 증명되어 있다(퍼셉트론 수렴 정리).

선을 움직이는 두 손잡이 (31쪽)

구분선은 w1·x1 + w2·x2 + b = 0이다. 가중치 w1, w2는 선의 기울기를 정하고, 편향 b는 선이 원점에서 얼마나 떨어져 있는지(오프셋)를 정한다. 학습이란 이 세 값을 조금씩 고쳐서 ●와 ▲를 가르는 선을 찾는 과정이다.

새로운 사람 판정하기 학습에 쓰지 않은 데이터

★로 그래프에 표시된다. 학습 전과 후의 판정을 비교해 보자. (실제 비만 판정은 BMI 등 더 복잡한 기준을 쓴다.)

한눈에 정리
  1. MCP 뉴로드: 0/1 입력을 더하고(g), 합이 θ 이상인지 판정(f)한다. y = f(g(x))
  2. θ = 2면 AND, θ = 1이면 OR, 억제성(×−1) 입력을 쓰면 NOT. 이걸 짜 맞추면 디지털 연산을 모두 할 수 있다.
  3. XOR처럼 선 하나로 나눌 수 없는 규칙은 뉴로드를 여러 개 연결해야 한다.
  4. 퍼셉트론: 어떤 값이든 입력받아 가중치를 곱해 더하고, 편향 b를 더해 0보다 크면 +1, 아니면 −1을 낸다.
  5. 퍼셉트론은 틀릴 때마다 w와 b를 고쳐서 구분선을 스스로 찾는다. 이것이 MCP에는 없던 ‘학습’이다.
  6. 단, 데이터가 직선 하나로 나뉠 때(선형 분리 가능)만 학습이 끝난다.

STEP 1에서 고른 내 예상: 아직 고르지 않음

Q1

입력이 x1, x2, x3 세 개이고 θ = 2인 MCP 뉴로드는 어떤 규칙일까?

답 보기
세 입력 중 2개 이상이 1이면 1을 내보낸다. 즉 다수결 뉴로드다. (1,1,0)이면 합 2 ≥ 2라서 1이고, (1,0,0)이면 합 1 < 2라서 0이다.
Q2

입력이 n개일 때 AND와 OR을 만들려면 θ를 각각 얼마로 해야 할까?

답 보기
AND는 합이 n일 때만 켜져야 하므로 θ = n이다. OR은 하나만 1이어도 켜져야 하므로 θ = 1이다.
Q3

구분선 w1·x1 + w2·x2 + b = 0을 x2에 대해 정리해 보자. 기울기와 y절편은 w1, w2, b로 어떻게 나타날까?

답 보기
x2 = −(w1/w2)·x1 − b/w2 (단, w2 ≠ 0). 기울기는 −w1/w2로 가중치끼리의 비율이 정하고, y절편은 −b/w2로 편향이 선을 위아래로 밀어 준다. 31쪽에서 말한 “가중치는 기울기, 편향은 오프셋”이 바로 이 뜻이다.
Q4

STEP 5에서 XOR은 퍼셉트론으로도 만들 수 없었다. 그럼 STEP 6처럼 학습을 시키면 XOR을 배울 수 있을까?

답 보기
배울 수 없다. 퍼셉트론 하나는 결국 직선 하나를 긋는다. XOR의 네 점은 어떤 직선으로도 ●와 ▲로 나눌 수 없다(선형 분리 불가능). 그래서 틀린 점이 늘 남고 학습이 영원히 끝나지 않는다. 해결하려면 STEP 4처럼 뉴런을 여러 층으로 쌓아야 한다.
Q5

MCP 뉴로드와 퍼셉트론의 가장 큰 차이를 한 문장으로 말해 보자.
