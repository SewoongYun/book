공분산 행렬의 고유벡터가 왜 주성분일까

책 200~201쪽 PCA 설명을 손으로 돌려보며 따라가기

  1. 공분산 행렬은 속성들이 서로 어떻게 함께 흩어지는지 적어둔 표다.
  2. 그 행렬의 고유벡터는 데이터 구름(타원)의 축 방향이고, 고윳값은 그 방향으로의 분산이다. 가장 큰 고윳값의 고유벡터가 제1주성분이다.
  3. 분산이 큰 축만 남기면 차원이 줄어든다. 하지만 분산이 작은 축에 중요한 정보가 숨어 있을 수도 있다(소방차 예시).

01공분산 행렬 읽는 법

키와 몸무게, 두 속성을 가진 50명의 데이터다. 각 속성에서 평균을 빼두었기 때문에 원점이 '평균인 사람'이다. 상관 정도를 바꾸면서 행렬이 어떻게 변하는지 보자.

읽는 법은 세 가지다.

  • 대각 원소는 속성 하나가 혼자 얼마나 퍼져 있는지(분산)다.
  • 비대각 원소는 두 속성이 같이 커지면 양수, 반대로 움직이면 음수, 무관하면 0 근처인 공분산이다. 슬라이더를 0으로 내리면 비대각이 0 가까이 떨어진다.
  • Cov(키, 몸무게) = Cov(몸무게, 키)라서 항상 대칭이다. 속성이 n개면 n×n 정사각행렬이다. 사람 수 m과는 상관없이 속성 수만큼 커진다. 책에서 "점점 커질 것"이라는 말이 이 뜻이다.

02밑줄 친 명제를 직접 확인하기

공분산 행렬의 고유벡터는 원래 행렬 X의 주성분이다.

주성분은 "데이터를 한 직선 위에 그림자처럼 투영했을 때, 그림자들이 가장 넓게 퍼지는 방향"이다. 아래에서 직선을 돌려보자. 파란 점들이 각 사람의 그림자(투영)다. 그림자의 분산이 최대가 되는 각도를 찾으면, 그 방향이 정확히 공분산 행렬의 고유벡터와 겹친다.

이 방향으로 투영한 분산 0, 가능한 최댓값 λ₁ = 0
직선을 돌려서 막대를 끝까지 채워보자.
왜 하필 고유벡터인가: 라그랑주 승수법으로 보기

단위벡터 u 방향으로 투영하면 각 점 p의 그림자 위치는 p·u다. 평균이 0이므로 그림자들의 분산은 아래와 같다.

Var(u) = 1m−1 Σ (p·u)² = uᵀ C u

|u| = 1 조건에서 이걸 최대화하면 (라그랑주 승수법)

∇[ uᵀCu − λ(uᵀu − 1) ] = 0  ⇒  C u = λ u

즉 분산이 극값이 되는 방향은 C의 고유벡터뿐이고, 그때의 분산은 uᵀCu = λuᵀu = λ다. 그래서 가장 큰 고윳값 λ₁의 고유벡터가 제1주성분이고, λ₁이 그 방향의 분산이다. 위 막대의 최댓값이 λ₁인 이유다.

미분 없이 고등학교 대수만으로 보는 방법은 03 탭에 있다.

03왜 고윳값이 가장 큰 고유벡터가 분산이 최대인 방향일까

어느 방향 u로 투영한 분산이든 고윳값들의 가중평균이다. 가중평균은 가장 큰 값을 넘을 수 없으니 최대는 λ₁이고, 그 최대는 u = v₁일 때 나온다.

1방향 u로 투영한 분산은 uᵀCu

점수 벡터는 Xu다. 평균이 0이니까 점수의 제곱합은

(Xu)ᵀ(Xu) = uᵀ(XᵀX)u = uᵀCu

책처럼 C = XᵀX로 둔다. m−1로 나누는 상수배는 결론에 영향이 없다.

2u를 고유벡터로 분해하기

C는 대칭행렬이라 서로 수직인 단위 고유벡터 v₁, …, vₙ를 갖는다(스펙트럴 정리). 고윳값은 λ₁ ≥ λ₂ ≥ … ≥ λₙ ≥ 0으로 놓는다. 그러면 어떤 단위벡터 u든

u = a₁v₁ + a₂v₂ + … + aₙvₙ,   a₁² + a₂² + … + aₙ² = 1

로 쓸 수 있다. aᵢ = u·vᵢ는 u가 각 고유벡터 방향으로 얼마나 기울어 있는지다.

3대입하기

Cvᵢ = λᵢvᵢ이고, i ≠ j이면 vᵢ·vⱼ = 0이라 교차항이 모두 사라진다.

uᵀCu = λ₁a₁² + λ₂a₂² + … + λₙaₙ²

4가중평균은 최댓값을 넘을 수 없다

가중치 aᵢ²는 모두 0 이상이고 합이 1이다. 그래서 위 식은 고윳값들의 가중평균이고

uᵀCu ≤ λ₁(a₁² + a₂² + … + aₙ²) = λ₁

등호는 a₁ = 1이고 나머지가 모두 0일 때, 즉 u = v₁일 때만 성립한다. 그때의 분산이 정확히 λ₁이다.

5숫자로 확인하기

05 탭의 예시 C = [[50, 40], [40, 38]]을 쓴다. λ₁ ≈ 84.45, λ₂ ≈ 3.55, v₁ ≈ (0.758, 0.653)이다. 방향을 돌리면 가중치가 바뀌면서 분산이 λ₂와 λ₁ 사이를 오간다.

6두 번째, 세 번째 주성분과 책 209쪽

두 번째 주성분은 v₁에 수직이라는 조건, 즉 a₁ = 0을 붙이고 같은 논리를 쓰면 된다. 남은 가중평균의 최댓값이 λ₂이고 그 방향이 v₂다. 세 번째도 마찬가지다.

책 209쪽에서 100×100 행렬 W의 고유벡터 100개 중 고윳값이 큰 3개를 골라 100×3 행렬 Wr을 만드는 것은, 분산을 가장 많이 담는 서로 수직인 세 방향을 고르는 일이다. 그다음 T = XWr로 각 행을 숫자 세 개로 줄인다. 205쪽 붓꽃 예시의 T = XWr도 같은 계산이다.

042차원을 1차원으로 줄이는 절차

책이 말한 m×2 행렬 X(m명, 속성 2개)의 절차를 그대로 따라가면 이렇다.

  1. 각 열에서 평균을 빼서 X를 만든다. 책의 '평균 보정'이 이 단계다.
  2. XᵀX를 계산한다. 2×2 대칭행렬이 나온다.
  3. 고유벡터 v₁, v₂와 고윳값 λ₁ ≥ λ₂를 구한다. 고유벡터는 데이터 타원의 장축·단축 방향이다.
  4. λ₁이 압도적으로 크면 v₂ 방향은 버리고, 모든 점을 v₁ 축에 투영한다. 각 사람이 숫자 하나로 표현된다.
v₁ (제1주성분, 장축) v₂ (단축)
v₁ 하나로 남는 분산의 비율 λ₁λ₁ + λ₂ = 0%

1번의 슬라이더로 상관을 낮추면 타원이 둥글어지고 비율이 떨어진다. 그러면 한 축만 남기면 잃는 게 많아진다. "나머지 방향은 무시해도 무방하다"는 말은 이 비율이 클 때만 맞다.

표기 메모: 책은 공분산 행렬을 XᵀX라고 썼지만, 엄밀한 표본공분산은 XᵀXm−1이다. 상수배는 고유벡터를 바꾸지 않고 고윳값만 같은 배수로 바꾸므로, 주성분 방향을 찾는 데는 차이가 없다.

2차원에서는 사소해 보이지만, 속성이 수백 개일 때 고윳값이 큰 축 몇 개만 남기면 데이터의 큰 흐름을 훨씬 적은 숫자로 볼 수 있다. 이게 201쪽 두 번째 문단의 요지다.

5이 점수가 뜻하는 것

  • 새 변수다. 점수는 키와 몸무게를 0.758 : 0.653 비율로 섞은 가중합이다. 일종의 '체격 점수'라고 보면 된다.
  • 고윳값 = 그 축의 퍼짐. 점수의 제곱합은 (−7.06)² + 1.31² + 5.75² ≈ 49.8 + 1.7 + 33.1 ≈ 84.5 = λ₁이다. m−1 = 2로 나눈 분산은 42.2이고, 이건 λ₁2와 같다.
  • 되돌리면 원래 점과 거의 같다. 점수 × v₁ + 평균을 하면 축 위의 점으로 돌아온다. A는 −7.06 × (0.758, 0.653) + (170, 60) ≈ (164.6, 55.4)로, 원래 (165, 55)에 아주 가깝다. 버린 v₂ 방향(λ₂ ≈ 3.55)에 있던 정보만 사라졌다는 뜻이다.

06소방차 예시: 분산이 작다고 쓸모없는 건 아니다

차량 데이터의 분산은 대부분 크기(길이)에서 나온다. 사다리 개수는 소방차만 1~2개이고 나머지는 전부 0이라 분산이 아주 작다. PCA는 분산만 보기 때문에 제1주성분은 거의 '크기' 축과 같아진다.

승용차·SUV 버스·트럭 소방차
제1주성분이 설명하는 분산 0%, 버려지는 제2주성분 0%

세로축(사다리 개수)은 보이도록 크게 늘려 그렸다. 실제 비율로 그리면 거의 납작한 한 줄이다.

버튼을 누르면 소방차가 버스·트럭 사이에 섞여서 구별이 안 된다. 분산의 99% 이상을 지켰지만, 과제가 "소방차 찾기"라면 정작 필요한 정보는 버린 1%에 있었다. 책이 케니 로저스 노래 가사를 인용한 것도 이 이야기다. 어떤 축을 남기고 어떤 축을 버릴지는 분산 크기가 아니라 무엇을 하려는지에 달려 있다.

한 줄 정리: 공분산 행렬은 "어느 방향으로 얼마나 퍼졌나"를 담고 있고, 고유벡터는 그 퍼짐의 축, 고윳값은 축 방향의 분산이다. PCA는 큰 축만 남겨 차원을 줄이는 방법이고, 작은 축에 답이 있을 수 있다는 점은 늘 따로 확인해야 한다.
